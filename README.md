## Game idea and story

Dhaka City Adventure is a text-based game about improving the environment of Dhaka. The city is facing problems such as litter in public places, plastic waste in rivers, a lack of trees, and poor recycling habits.

The player becomes a volunteer who wants to make Dhaka cleaner and greener. The player can visit different locations and perform environmental activities. These include cleaning a park, removing plastic from theVindREP?abat Tape? hardeveloped river, planting trees, and teaching students about recycling.

The game is suitable for young players because it does not contain violence or inappropriate content.

## Objective

The objective is to help improve Dhaka, the most densely populated city in the world by completing different environmental activities. The game also encourages the player to understand how small actions can make a city cleaner, healthier, and more sustainable.

## Operating principles

When the game starts, it asks for the player’s name and age. The program stores this information in variables and prints it on the screen.

If the player is under 12 years old, the program informs the player that they are under the required age and shuts down.

If the player is 12 or older, the program welcomes the player and displays the main menu. The player enters a command to select an activity. After completing a command, the main menu is displayed again.

The game continues until the player enters `lopeta`. Commands must be entered exactly as they appear in the menu.

## Functionalities

The current version includes the following functionalities:

* It asks for and displays the player’s name and age.
* It checks whether the player is at least 12 years old.
* It welcomes eligible players.
* It displays a command-line main menu.
* The `park` command allows the player to clean a park.
* The `river` command allows the player to remove plastic waste from the Buriganga River.
* The `garden` command allows the player to plant trees.
* The `school` command allows the player to teach students about recycling.
* It displays a different result for every valid command.
* It displays an error message when the player enters an unknown command.
* It displays the menu again after each activity.
* The `lopeta` command ends the game.
